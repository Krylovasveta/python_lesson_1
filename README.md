# Проект автоматизации тестирования веб-сервиса «Кинопоиск»

Данный репозиторий содержит комплект автотестов и тестовую документацию для проверки ключевого функционала сайта [kinopoisk.ru](https://www.kinopoisk.ru/).

## 📌 О проекте
Цель проекта — обеспечить контроль качества критически важных разделов сервиса: поиска фильмов, навигации меню и работы онлайн-кинотеатра. 

**Объект тестирования:**
* Поиск фильмов (по названию, жанру, году, режиссеру).
* Навигация главного меню («Магазин», «Подписки», «Каналы», «Спорт»).
* Онлайн-кинотеатр (карточки фильмов, кнопки воспроизведения).

## 🛠 Технологический стек
* **Язык:** Python 3.x
* **Фреймворк:** Pytest
* **Библиотека автоматизации:** Selenium WebDriver
* **Отчетность:** Allure Report
* **API тестирование:** Postman
* **Управление тестами:** Test IT

## 📝 Тестовая документация
В рамках проекта были разработаны:
1. **Тест-план:** анализ рисков, стратегия и сроки.
2. **26 тест-кейсов:** функциональные, нефункциональные и API-проверки.
3. **Чек-листы:** для кроссбраузерного и UX-тестирования.
   

## 🚀 Запуск автотестов

### Предварительные условия
Должен быть установлен Python и Chrome Browser.

1. **Клонировать репозиторий:**
2. **Установить зависимости:**
bash
pip install -r requirements.txt
3. **Запустить тесты:**
bash
pytest --alluredir=allure-results
4. **Генерация отчета Allure:**
bash
allure serve allure-results
