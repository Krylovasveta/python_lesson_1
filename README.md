# Проект: Автотесты Selenium (ветка lesson10)
Этот репозиторий содержит набор автоматизированных тестов для сайтов https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html и https://www.saucedemo.com/, реализованных на Python с использованием pytest и allure-pytest. Отчёты о результатах тестирования формируются в формате Allure.

Ветка разработки
**Текущая ветка:** lesson10.

## Предварительные требования
Перед запуском тестов убедитесь, что у вас установлены следующие компоненты:

**Python 3.12** или выше.
**Утилита командной строки Allure** (необходима для генерации и просмотра HTML-отчётов).
Установка зависимостей
Активируйте виртуальное окружение и установите необходимые пакеты:

**bash**
pip install -r requirements.txt
Убедитесь, что в списке зависимостей присутствует пакет allure-pytest:

**bash**
pip list | grep allure-pytest

**Установка Allure CLI**
Для генерации отчётов требуется установленная утилита allure.

**Windows**: рекомендуется использовать Scoop или скачать бинарный файл с .
**macOS**: brew install allure.
**Linux**: apt-get install allure или через snap.
Проверьте установку:

**bash**
allure --version
Запуск тестов и формирование отчёта
Все результаты тестирования сохраняются в папке allure-results.

Запуск всех тестов
Чтобы запустить все тесты и сформировать сырые данные для отчёта, выполните:

**bash**
pytest --alluredir
Эта команда:

Запускает все тесты, найденные в проекте.
Сохраняет XML-данные о результатах в директорию allure-results.
Запуск конкретных тестов (опционально)
Если нужно запустить только тесты из определённой папки или файла:

**bash**
Запуск тестов только из папки tests
pytest tests/ --alluredir=allure-results


**bash**
**Windows (PowerShell)**
Remove-Item -Path allure-results -Recurse -Force

**Windows (CMD)**
rmdir /s /q allure-results

**macOS / Linux**
rm -rf allure-results
После очистки снова запустите тесты командой из пункта «Запуск всех тестов».

## Просмотр отчёта Allure
У вас есть два способа посмотреть отчёт.

Способ 1: Интерактивный просмотр в браузере (рекомендуется)
Используйте команду allure serve, чтобы запустить локальный сервер и открыть отчёт в браузере:

**bash**
allure serve allure-results
Отчёт автоматически откроется в вашем браузере по адресу http://localhost:PORT. Сервер будет работать, пока вы не остановите его нажатием Ctrl+C в терминале.

Способ 2: Генерация статического отчёта
Если вам нужно сохранить отчёт как набор файлов (например, для отправки в чат или на почту):

**bash**
allure generate allure-results -o allure-report --clean
Отчёт будет сгенерирован в папке allure-report. Чтобы открыть его, просто откройте файл allure-report/index.html в любом браузере.


## Структура проекта (ключевые моменты)
tests/ — каталог с тестовыми сценариями.
pages/ — классы-страницы или клиенты API (например, projectapi.py).
allure-results/ — автоматически генерируемые файлы с результатами тестов (XML).

## Полезные команды
Команда	Описание
pytest -v	Запуск тестов с подробным выводом в консоль (без генерации Allure).
pytest --alluredir=allure-results	Запуск тестов с сохранением результатов для Allure.
allure serve allure-results	Запуск локального сервера для просмотра отчёта.
allure generate allure-results -o allure-report --clean	Генерация статического HTML-отчёта.
Что делать, если отчёт пустой или не открывается?
Проверьте, что папка allure-results не пуста. В ней должны быть XML-файлы. Если папка пуста — тесты не были запущены с флагом --alluredir.
Убедитесь, что allure установлен и доступен в PATH. Проверьте командой allure --version.
Очистите старые результаты и запустите тесты заново, чтобы исключить конфликты данных.
Как внести изменения и отправить код
Внесите правки в код тестов.
Запустите тесты и убедитесь, что они проходят.
Сформируйте отчёт (allure serve allure-results) и проверьте, что статусы тестов корректны.
